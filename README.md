# Endee GenAI RAG Project

## 📌 Project Overview
This project is a **Generative AI–based Document Question Answering system** built using **vector embeddings and semantic search**. It demonstrates the core concept of **Retrieval Augmented Generation (RAG)** by retrieving relevant information from documents using a vector database approach inspired by **Endee**.

Instead of relying only on keyword matching, the system understands the **semantic meaning** of both documents and user queries, enabling more accurate and intelligent responses.
