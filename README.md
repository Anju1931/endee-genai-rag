# Endee GenAI RAG Project

## 📌 Project Overview
This project is a **Generative AI–based Document Question Answering system** built using **vector embeddings and semantic search**. It demonstrates the core concept of **Retrieval Augmented Generation (RAG)** by retrieving relevant information from documents using a vector database approach inspired by **Endee**.

Instead of relying only on keyword matching, the system understands the **semantic meaning** of both documents and user queries, enabling more accurate and intelligent responses.

---

## 🎯 Key Features
 Semantic search using vector embeddings  
- Document-based question answering  
- Retrieval layer of a RAG pipeline  
- Lightweight and easy to understand  
- Designed as a project-based evaluation for Endee Labs  

---

## 🧠 How It Works
1. Documents are converted into numerical embeddings using a transformer model  
2. Embeddings are stored in a vector format (Endee-style vector database)  
3. User queries are also converted into embeddings  
4. Similarity search is performed to find the most relevant document  
5. The best-matching result is returned as the answer
